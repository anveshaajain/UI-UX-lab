# UI-UX Design Lab

## 📖 Overview
This repository contains the programs and assignments completed as part of the **UI-UX Design Laboratory**. The objective of this lab is to learn and implement the fundamentals of User Interface (UI) and User Experience (UX) design through practical web development exercises using HTML and CSS.

---

## 🎯 Objectives
- Understand the principles of UI and UX design.
- Design simple, user-friendly web interfaces.
- Develop responsive and visually appealing web pages.
- Gain hands-on experience with HTML and CSS.
- Practice creating structured and interactive web layouts.

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- Git
- GitHub

---

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/anveshaajain/UI-UX-lab.git
```

2. Open the project folder.

3. Open any `.html` file in your preferred web browser.

---

## 📚 Learning Outcomes
- Creating static web pages using HTML.
- Applying CSS for styling and layout.
- Understanding navigation between multiple web pages.
- Designing clean and user-friendly interfaces.
- Using Git and GitHub for version control.
